# Elevator Pitch

## One Sentence

The NHS Pathway Escalation and Evidence Agent is a synthetic Google ADK demonstration that preserves deterministic pathway calculations, retrieves controlled evidence, applies guardrails and requires explicit human review before any escalation draft is approved for demonstration.

## 30-Second Pitch

Time-sensitive operational pathway review needs consistency, evidence and accountability. This project demonstrates a safer agent pattern: deterministic services calculate pathway status and risk, Google ADK agents coordinate the workflow, MCP-compatible local capabilities provide structured data and evidence, reusable Agent Skills package core tasks, and guardrails plus human review prevent autonomous escalation. The public demo uses synthetic data only and defaults to offline mock-MCP mode.

## 60-Second Pitch

The NHS Pathway Escalation and Evidence Agent is an Agents for Good capstone project showing how agent systems can assist operational review without replacing human judgement. A synthetic case is selected, deterministic logic calculates elapsed time, breach status and operational risk, and a Google ADK multi-agent workflow retrieves evidence and drafts a non-clinical escalation summary. MCP interoperability demonstrates a clean tool boundary, Agent Skills make capabilities reusable, and guardrails check for unsafe claims, prompt injection, deterministic overrides and review bypass. The human-review workflow records explicit approve, amend or reject decisions while preserving `submitted=false` and `authenticated_identity=false`. Evaluation uses a controlled 30-case synthetic benchmark and committed evidence. The result is a portfolio-quality demonstration of accountable, evidence-grounded agent architecture.
