# Five-Minute Demo Script

Target duration: under 5 minutes.

Primary case: `SYN-CANCER-62-003`. This case is suitable because it is synthetic, visibly breached, has a critical operational risk level, retrieves controlled evidence, triggers the ADK workflow and requires human review.

## 0:00-0:30 - Problem and Value

Open: Streamlit Overview tab.

Narration:

"This is the NHS Pathway Escalation and Evidence Agent, an Agents for Good capstone project. It demonstrates how an agent system can support time-sensitive operational pathway review without making clinical decisions. The problem is that pathway review needs consistent calculations, evidence, auditability and human accountability. This demo uses synthetic data only and does not connect to live NHS systems."

Point at: safety banner and badges.

Do not say: "This is production-ready" or "This is clinical advice."

## 0:30-0:55 - Solution Overview

Open: Overview tab.

Narration:

"The solution combines deterministic pathway calculations, Google ADK multi-agent orchestration, local MCP interoperability, reusable Agent Skills, guardrails and explicit human review. The public demo defaults to mock-MCP mode. That means it exercises the ADK and MCP workflow locally, but it does not call Gemini and does not require credentials."

Point at: default execution mode `mock-mcp`.

## 0:55-1:30 - Architecture

Open: Architecture and Limitations tab.

Narration:

"The architecture separates responsibilities. Deterministic services calculate pathway status and risk. ADK agents coordinate the workflow. MCP-compatible capabilities provide synthetic case data, pathway rules and controlled evidence. Guardrails check unsafe or unsupported content. The review service records human decisions. The deployment package is Cloud Run-ready, but this milestone does not deploy the app."

Point at: workflow sequence from User to Human Reviewer.

## 1:30-2:45 - Demonstration Using Primary Case

Open: Select Case tab. Select `SYN-CANCER-62-003`.

Narration:

"I will use `SYN-CANCER-62-003`, a synthetic Cancer 62-day operational pathway case. The case is marked synthetic, has no real patient data and includes operational flags."

Open: Deterministic Assessment tab. Click "Run deterministic assessment."

Narration:

"The deterministic engine calculates the target, elapsed time, target consumption, variance, breach status and risk. Here the breach status is `BREACHED`, the risk score is `7.5`, and the risk level is `CRITICAL`. These values are not generated by a language model. They come from deterministic rules and are the source of truth."

Point at: breach status, risk score, risk level, audit trace ID, demonstration-only warning.

## 2:45-3:25 - MCP, Agent Skills and ADK Workflow

Open: Agent Workflow tab. Click "Run agent workflow."

Narration:

"Now I run the ADK workflow in mock-MCP mode. The Coordinator Agent routes work to specialist agents for pathway, risk, evidence, escalation and review. The tool table shows local tool and MCP-style invocations. The draft escalation preserves deterministic values and cites controlled evidence. Agent Skills are also implemented and evaluated for pathway identification, risk calculation, evidence retrieval and escalation drafting."

Point at: workflow sequence, tool or MCP invocations, draft escalation and evidence references.

Do not say: "Gemini produced this response."

## 3:25-4:05 - Security and Human Review

Open: Security and Guardrails tab.

Narration:

"The guardrail layer checks deterministic integrity, prompt injection patterns, unsupported claims, clinical advice language, personal data patterns, secrets and review bypass. These controls are not perfect, and the UI says so clearly."

Open: Human Review tab. Click "Prepare review." Enter reviewer alias `demo-reviewer`. Select approve for demonstration. Enter "Approved for synthetic demonstration only." Click "Apply review decision."

Narration:

"The system cannot approve itself. A reviewer alias must be entered, and the record still says `submitted=false` and `authenticated_identity=false`. This is a demonstration decision, not clinical or operational approval."

## 4:05-4:35 - Evaluation Results

Open: Evaluation Evidence tab.

Narration:

"The evaluation evidence is committed in the repository. It uses a controlled 30-case synthetic benchmark, six cases per pathway. The overall controlled benchmark pass rate is 1.0. Deterministic accuracy, agent deterministic preservation, skill checks, evidence grounding, security, review controls and reproducibility all pass on the controlled datasets. These are synthetic benchmark results, not production performance claims."

Point at: run ID, case count, pathway distribution and metric table.

## 4:35-5:00 - Limitations and Conclusion

Open: Architecture and Limitations tab.

Narration:

"The limitations are important: synthetic data only, demonstration targets, no clinical authority, no live NHS integration, no authenticated reviewer identity, no verified live Gemini run and no Cloud Run deployment in this milestone. The main contribution is the architecture: deterministic truth, bounded agents, evidence grounding, guardrails and human accountability."

End on: Overview or title header.
