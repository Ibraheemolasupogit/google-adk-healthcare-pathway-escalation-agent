# MCP Tool Catalogue

## Case Data

Tools: `get_case`, `list_cases`, `list_cases_by_pathway`, `validate_case`.

Resources: `case://synthetic/index`, `case://synthetic/{case_id}`.

## Pathway Rules

Tools: `get_pathway_rule`, `list_pathway_rules`, `calculate_elapsed_time`, `determine_breach_status`, `run_pathway_assessment`.

Resources: `pathway://rules/index`, `pathway://rules/{pathway_code}`.

## Policy Evidence

Tools: `search_evidence`, `get_evidence`, `list_evidence`, `get_evidence_for_pathway`.

Resources: `evidence://local/index`, `evidence://local/{evidence_id}`, `evidence://local/pathway/{pathway_code}`.
