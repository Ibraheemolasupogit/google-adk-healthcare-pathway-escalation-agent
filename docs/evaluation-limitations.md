# Evaluation Limitations

The Milestone 6 evaluation framework is intentionally offline and synthetic.

- It does not evaluate live Gemini model behavior.
- It does not use real patient data, real NHS operational feeds or live NHS policy endpoints.
- It does not prove clinical safety or operational readiness.
- It measures deterministic and mock-agent behavior against controlled expected outputs.
- It does not replace expert validation of pathway targets, local policy, clinical governance or human-review procedures.
- Security metrics describe the included synthetic attack dataset only.
- Reproducibility hashes normalise documented volatile fields and do not guarantee identical infrastructure behavior in future deployed environments.

The project remains a demonstration system for education, competition development and architecture evidence.

Milestone 7 displays these limitations in the public UI and keeps final Kaggle write-up, final screenshots and final video creation out of scope.
