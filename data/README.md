# Data

This directory contains synthetic demonstration data only. It must not contain real patient-identifiable information, NHS numbers, hospital numbers, addresses, dates of birth, or operational records copied from live systems.

`pathway_targets.json` contains structured illustrative target rules for software design and testing. Values must be validated against current authoritative guidance before any operational use.

`synthetic_cases.json` contains 15 synthetic cases across Cancer 2WW, Cancer 28-Day Faster Diagnosis, Cancer 62-Day, RTT 18-Week and UEC 4-Hour demonstration pathways.
